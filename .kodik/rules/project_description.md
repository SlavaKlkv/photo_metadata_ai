
Описание: AI-сервис для автоматической обработки фотографий: анализ изображений, генерация метаданных, переименование файлов и экспорт информации в CSV. 
Веб-инструмент для фотографов, которые продают фото на стоках. Закидываешь папку с фотографиями → AI анализирует каждое фото, генерирует названия, описания и ключевые слова → встраивает метаданные в файлы и выдаёт готовый CSV для загрузки на Getty/Shutterstock/Adobe.
